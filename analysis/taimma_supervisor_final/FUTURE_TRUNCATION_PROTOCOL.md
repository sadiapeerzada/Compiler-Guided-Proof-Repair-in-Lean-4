# Future diagnostic-truncation pilot — not authorized or executed

This is a proposal, not a preregistration. Existing V7/V8 test traces show no truncation and provide no randomized evidence for a diagnostic-length effect. Any prospective study must use newly constructed, independently reviewed theorem families disjoint from all inspected development/test cases. Use PR20's `PROPOSED_EXPERIMENT.md` for the broader diagnostic-content question; this outline addresses length only.

Before model access, freeze 120 new theorem types and three seeds, plus a separate development pool used solely to finalize prompts, verifier policy and runtime feasibility. Independently validate reference proofs, NL statements and split independence. Generate one initial candidate per theorem/seed, then compare the exact same failed predecessor in no-diagnostic, full-diagnostic, and 128/256/384-token prefix arms. Freeze a structured error-selection rule, truncation direction, tokenizer/model revisions, donor-free feedback semantics, decoding and execution-order randomization. Report initial successes separately; do not select test cases based on which repair improves.

Use one repair per arm, identical output cap of 1200 tokens and identical 8192 total context allowance. Pad repair prompts to a predeclared common tokenizer length with the same neutral marker scheme, keeping fixed-theorem and predecessor positions consistent where feasible. Padding itself can affect behavior and must be disclosed. Full-diagnostic overflow is an unavailable condition under the frozen policy, not permission to silently truncate the full arm or change the theorem cohort. Account for incomplete outcomes using predeclared bounds. Log actual token lengths, padding, verification, errors and consumed intents.

Primary endpoint: strict kernel-verified first repair for full versus 128-token prefix, paired and theorem-clustered across three seeds. Other contrasts are exploratory unless multiplicity handling is specified before execution. Retain all seeds of a theorem in each cluster; use family sensitivity for any residual dependence. Freeze resampling method/seed and a script on development-only fixtures before held-out access. Reject sorry/admit/axiom bypasses and statement changes.

Budget ceiling: 360 initial generations and at most 1800 repairs, 2160 total calls. Stop at that cap or a predeclared development-calibrated wall-time allocation, whichever occurs first; no efficacy-based early stopping or adaptive example selection. No compute or monetary quote is asserted. With only 120 independent theorem means in [−1,1], a worst-case normal-approximation 95% half-width is about 17.9 percentage points; this pilot cannot guarantee precision for a small effect. Failure conditioning, family dependence and missingness may further weaken precision. Any larger study/power target must be fixed before inspecting test repairs and separately authorized.
