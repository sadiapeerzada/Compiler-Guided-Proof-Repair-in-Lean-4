STATEMENT: For any function \( f : \mathbb{N} \to \mathbb{N} \) and any natural number \( n \), the function \( f \) applied \( n \) times to 0 is equal to \( f \) applied \( n \) times to \( f(0) \).

LEAN:
```lean
theorem sprint_development_0092 (f : ℕ → ℕ) (n : ℕ) : f^[n] 0 = f^[n] (f 0) := by
  induction n with
  | zero => simp [Function.iterate_zero]
  | succ n' => simp [Function.iterate_succ, Function.iterate_succ_apply]
```
