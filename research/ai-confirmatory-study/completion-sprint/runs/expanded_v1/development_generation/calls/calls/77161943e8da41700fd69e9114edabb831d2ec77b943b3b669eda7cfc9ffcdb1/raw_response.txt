STATEMENT: For any finite set `s` and any element `a` in `s`, the cardinality of the set `s` minus the cardinality of the set `s` without `a` is equal to 1.

LEAN:
```lean
theorem sprint_development_0119 {α : Type*} {s : Finset α} {a : α} (ha : a ∈ s) : s.card - (s.erase a).card = 1 := by
  rw [Finset.erase_card, Finset.card_erase_of_mem ha]
```
