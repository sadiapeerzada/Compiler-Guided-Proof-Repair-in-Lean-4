STATEMENT: For any list `l` and natural number `n`, if `n` is less than the length of `l`, then `List.drop n (List.take n l) = l`.

LEAN:
```lean
theorem sprint_development_0050 {u} {α : Type u} {l : List α} {n : ℕ} (h : n < l.length) :
  List.drop n (List.take n l) = l :=
by
  rw [List.take_eq_self_iff]
  exact h
```
