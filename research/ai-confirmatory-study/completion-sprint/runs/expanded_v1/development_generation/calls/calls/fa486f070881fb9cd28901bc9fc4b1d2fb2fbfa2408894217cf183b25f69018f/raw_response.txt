STATEMENT: For any function \( f : \mathbb{N} \to \mathbb{N} \) and any natural number \( n \), if \( f(n) = n \), then \( f^[n] = id \).

LEAN:
```lean
theorem sprint_development_0028 {f : ℕ → ℕ} {n : ℕ} (h : f n = n) : f^[n] = id := by
  induction n with
  | zero => simp [Function.iterate_zero, Function.iterate_zero_apply]
  | succ n' ih => 
    have : f^[n'] = id := ih (h (f n'))
    simp [Function.iterate_succ, Function.iterate_succ_apply, Function.iterate_zero, Function.iterate_zero_apply, Function.iterate_id, h]
```
