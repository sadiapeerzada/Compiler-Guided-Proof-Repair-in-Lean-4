STATEMENT: For any integers \(a\), \(b\), and \(c\) where \(b > 0\) and \(c > 0\), the remainder of \(a\) divided by \(b\) plus the remainder of \(a\) divided by \(c\) is less than or equal to the remainder of \(a\) divided by the least common multiple of \(b\) and \(c\).

```lean
theorem sprint_development_0081 (a b c : ℤ) (hb : b > 0) (hc : c > 0) : a % b + a % c ≤ a % (b * c / gcd b c) := by
  rw [Int.emod_eq_sub_self_emod]
  have : a % b = a - b * (a / b) := by ring
  have : a % c = a - c * (a / c) := by ring
  rw [this, this] at *
  have : a - b * (a / b) + a - c * (a / c) ≤ a - (b * (a / b) + c * (a / c)) := by linarith
  rw [Int.emod_eq_sub_self_emod] at this
  have : b * (a / b) + c * (a / c) = a / (b * c / gcd b c) := by ring
  rw [this] at this
  linarith
```
