STATEMENT: For any integers \(a\), \(b\), and \(c\), if \(\gcd(a, b) = 1\) and \(c\) divides both \(a\) and \(b\), then \(c\) must be 1.

LEAN:
```lean
theorem final_dev_0064 (a b c : ℤ) (h1 : gcd a b = 1) (h2 : c ∣ a) (h3 : c ∣ b) : c = 1 := by
  have h4 : ∃ x y : ℤ, a = x * b + y * a := by
    rw [h1] at h1 
    exact int.exists_linear_combination h1
  obtain ⟨x, y, h5⟩ := h4
  have h6 : c ∣ (x * b + y * a) := by
    rw [h5] at h5 
    exact int.dvd_add (int.dvd_mul_left h2 x) (int.dvd_mul_left h3 y)
  have h7 : c ∣ 1 := by
    rw [int.dvd_one] at h6 
    exact h6
  exact int.one_unique h7
```
