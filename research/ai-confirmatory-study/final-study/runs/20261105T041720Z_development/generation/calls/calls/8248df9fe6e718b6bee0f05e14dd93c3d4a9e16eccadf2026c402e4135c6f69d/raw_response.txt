STATEMENT: For any natural numbers \(a\), \(b\), and \(q\), if \(a = bq + r\) where \(0 \leq r < b\), then \(q \leq \frac{a}{b}\).

LEAN:
```lean
theorem final_dev_0214 (a b : Nat) (q : Nat) (h : a = b * q + Nat.mod a b) : q ≤ a / b := by
  classical
  have h1 : Nat.mod a b < b := by
    rw [h]
    exact Nat.mod_lt a b
  have h2 : a = b * q + Nat.mod a b := by
    rw [h]
  have h3 : a / b * b ≥ a := by
    rw [h2]
    exact Nat.div_le_of_mod h1
  have h4 : a / b ≥ q := by
    rw [h3]
    exact Nat.le_div_of_mod h1
  exact h4
```
