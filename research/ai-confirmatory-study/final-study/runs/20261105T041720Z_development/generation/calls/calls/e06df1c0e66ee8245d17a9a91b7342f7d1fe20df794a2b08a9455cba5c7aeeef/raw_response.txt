STATEMENT: For all real numbers \(a\), \(b\), and \(c\) such that \(a > 0\) and \(b^2 - 4ac < 0\), the quadratic polynomial \(ax^2 + bx + c\) is always positive.

LEAN:
```lean
theorem final_dev_0090 (a b c : ℝ) (h_a_pos : a > 0) (h_discr_neg : b^2 - 4 * a * c < 0) : ∀ x : ℝ, a * x^2 + b * x + c > 0 := by
  intro x
  have h1 : a * x^2 + b * x + c = a * (x + b / (2 * a))^2 + c - b^2 / (4 * a) := by
    rw [mul_add, add_assoc, mul_div_cancel_left (ne_of_gt h_a_pos)]
  have h2 : c - b^2 / (4 * a) > 0 := by
    rw [h_discr_neg]
    exact div_pos (neg_lt_of_lt h_discr_neg) (ne_of_gt h_a_pos)
  have h3 : a * (x + b / (2 * a))^2 ≥ 0 := by
    rw [mul_self_nonneg]
    exact h_a_pos
  exact le_add_of_nonneg_right h3 h2
```
