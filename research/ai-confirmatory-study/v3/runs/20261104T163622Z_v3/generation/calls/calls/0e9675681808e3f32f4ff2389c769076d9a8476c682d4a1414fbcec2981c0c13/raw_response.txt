STATEMENT: For any sets A, B, and C, if x is in the set difference of A and B, and x is also in the set difference of B and C, then x is in the set difference of A and C.

LEAN:
```lean
theorem v3_gen_004 {α : Type*} (A B C : Set α) (x : α) (h1 : x ∈ A \ B) (h2 : x ∈ B \ C) : x ∈ A \ C := by
  simp [set.difference_eq]
  exact h1
```
