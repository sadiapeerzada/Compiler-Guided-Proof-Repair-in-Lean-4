ID
v2_gen_002

STATEMENT
For all natural numbers \(a\), \(b\), and \(c\), if \(a \leq b\) and \(b \leq c\), then \(a \leq c\).

TARGET
theorem v2_gen_002 (a b c : ℕ) (h1 : a ≤ b) (h2 : b ≤ c) : a ≤ c :=
by
  apply le_trans h1 h2

CATEGORY
natural-number inequalities

FAMILY
transitivity of inequality
